# Student Performance Analysis

## Project Overview

This project uses Exploratory Data Analysis (EDA) to explore how study time, absences, past failures, school support, age, and sex relate to students' final mathematics grades.

## Objectives

- Understand the dataset and its structure.
- Check missing values and duplicate records.
- Analyze final-grade distributions and summary statistics.
- Explore relationships between student-related factors and final grades.
- Create visualizations to identify patterns.

## Dataset

- **Source:** UCI Student Performance Dataset
- **Records:** 395 students
- **Columns:** 33
- **Target variable:** `G3` (final mathematics grade)

## Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Data inspection and quality checks
- Descriptive statistical analysis
- Study time vs. final grade
- Absences vs. final grade
- Past failures vs. final grade
- School support vs. final grade
- Age and sex comparisons
- Overall final-grade distribution

## Key Findings

- Students with no past failures had a higher average final grade than students with previous failures.
- Average final grades varied across study-time categories.
- The dataset contained no missing values or exact duplicate rows across all 33 original columns.
- The overall average final grade was approximately **10.42 out of 20**.

## Conclusion

This project demonstrates how EDA can be used to inspect data, summarize student performance, and visualize patterns in academic results. The findings show associations within the dataset and do not establish cause and effect.
